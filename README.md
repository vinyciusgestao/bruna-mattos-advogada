# Site de Bruna Mattos, advogada

Site estático (HTML, CSS e JavaScript) de Bruna Mattos, advogada inscrita na OAB/RR sob o nº 2872, com atendimento em Pacaraima (RR) e online.

Publicado pelo GitHub Pages: https://vinyciusgestao.github.io/bruna-mattos-advogada/

## O que editar

- **Google Analytics:** cole o ID de medição (G-XXXXXXXXXX) na constante `GA_ID`, no topo de `assets/app.js`. Ele só carrega depois que o visitante aceita os cookies.
- **Número do WhatsApp:** `559591367145` aparece nos links `wa.me` das páginas HTML e na constante `WHATSAPP` de `assets/app.js`.
- **Domínio próprio:** se o site ganhar um domínio, troque o endereço em `canonical`, `og:url`, `og:image`, `sitemap.xml` e `robots.txt`.

## Páginas

`index.html` (início), `privacidade.html`, `termos.html`, `obrigado.html` (depois do formulário) e `404.html`.
